ANIK PREMIUM PORTFOLIO — GITHUB PAGES

IMPORTANT:
Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do NOT upload the ZIP file itself.

Your repository root must look like:
index.html
style.css
script.js
.nojekyll
assets/
  images/
  icons/
  logo/

Then:
1. GitHub → Repository → Settings → Pages
2. Source: Deploy from a branch
3. Branch: main
4. Folder: / (root)
5. Save
6. Open the generated GitHub Pages URL.

For the custom domain:
Settings → Pages → Custom domain → anik.qzz.io
Then configure the DNS records GitHub shows for your domain.

If opening the ZIP locally:
Extract the ZIP first, then open index.html from the extracted folder.
Do not move index.html outside the project folder because CSS/JS/images use relative paths.
