# Md Emon Hassan Anik — Modern Personal Portfolio

GitHub Pages-ready static personal website for **Md Emon Hassan Anik — Student & Developer**.

## Included
- Premium glassmorphism UI
- Mobile + desktop responsive layout
- 4 selectable themes: Midnight, Pearl, Aurora, Rose
- Animated typing text, scroll reveal, gallery lightbox and UI effects
- Personal photo gallery
- Facebook, Instagram, WhatsApp, TikTok, Threads, Telegram and Email
- SEO metadata + Open Graph + Twitter card
- Person Schema.org JSON-LD
- robots.txt + sitemap.xml
- No PHP, no database, no admin panel

## Deploy on GitHub Pages
Keep `index.html` in the repository root and keep the `assets` folder beside it.

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## SEO note
The site is technically SEO-ready, but Google ranking is not guaranteed by code alone. After publishing, submit the site/sitemap in Google Search Console and keep the content/links updated.
